================================================================================
                         REPLIT LIMITATIONS (FREE)
================================================================================

⚠️  Important to Know:

1. DATABASE NOT PERSISTENT (Free Plan)
   └─ Data hilang saat restart
   └─ Upgrade ke paid untuk persistent
   └─ But: Good untuk testing & demo

2. SERVER SLEEP (Free Plan)
   └─ Sleep kalau no traffic 1 hour
   └─ Wake up saat ada request (delay 30s)
   └─ Upgrade untuk always-on

3. FILE UPLOAD EPHEMERAL
   └─ Uploaded files bisa hilang
   └─ Use cloud storage untuk production (S3, Blob, dll)
   └─ Or: Upgrade ke paid Replit

4. RESOURCE LIMITED
   └─ 256 MB RAM shared
   └─ CPU limited
   └─ Fine untuk demo/small projects

SOLUTION: Upgrade ke Shared Hosting / VPS untuk Production
  └─ See: DEPLOYMENT_GUIDE.md untuk options
