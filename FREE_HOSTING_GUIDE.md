## 🚀 Quick Start (Choose One)

### **OPTION 1: REPLIT** (RECOMMENDED) ⭐

**Setup Time**: 15-20 minutes
**Difficulty**: ⭐⭐ (Easy)

**Panduan Lengkap**: Buka `REPLIT_SETUP.md`

**Quick Steps**:
1. Sign up di https://replit.com
2. Import project dari GitHub branch `tampilkan`
3. Setup MySQL database (auto create)
4. Import SQL schema
5. Update `config/koneksi.php`
6. Create `uploads` folder
7. Click "Run"
8. Done! ✅

**Keuntungan**:
- ✅ PHP native support
- ✅ MySQL built-in
- ✅ Simple setup
- ✅ Fast deployment
- ✅ Good performance for demo

**Limitasi**:
- Free plan: Database/files hilang saat restart
- Server tidur kalau no traffic 1 jam
- Limited resources

**Hanya gunakan Glitch jika**:

## 📞 Support & Troubleshooting

### **Replit Issues**
- Database not connecting? Check `config/koneksi.php`
- File upload error? Create `uploads` folder + chmod
- Server not running? Click "Run" button

See `REPLIT_SETUP.md` for detailed troubleshooting

### **Glitch Issues**
- PHP not working? Check `.replit` config file
- Need help? See `GLITCH_SETUP.md`

## 🚀 Upgrade ke Hosting Berbayar

Kalau sudah testing dan ingin production:

### **Shared Hosting** (Recommended) ⭐
- **Cost**: Rp 25-100k/bulan
- **Providers**: IDCloudHost, Niagahoster, Rumah Web
- **Setup**: 30-60 minutes
- **Database**: Persistent
- **File Upload**: Persistent
- **Performance**: Good for small-medium projects

See `QUICK_SETUP.md` or `DEPLOYMENT_GUIDE.md` for setup

### **VPS Cloud**
- **Cost**: Rp 50-150k/bulan
- **Providers**: DigitalOcean, Vultr, Contabo
- **Setup**: 1-2 hours
- **Performance**: Better for scaling
- **Control**: Full control

See `DEPLOYMENT_GUIDE.md` for setup
